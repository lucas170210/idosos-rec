# Guia Digital Seguro

Dashboard acessível para orientação de pessoas idosas sobre segurança digital.

A página agora apresenta as orientações em cards clicáveis. Cada card abre um modal com o conteúdo completo, botão de leitura em voz alta, fechamento por botão, clique fora ou tecla `Esc`, além de foco acessível para teclado. O projeto mantém as abas do simulador de WhatsApp, do quiz e do plano de emergência, com suporte a aumento de fonte e alto contraste.

## Arquivos

- `index.html`: estrutura do dashboard, cards, abas e modal.
- `estilo.css`: identidade visual, responsividade e estados de acessibilidade.
- `script.js`: interações dos cards, leitura em voz alta, navegação, simulador e quiz.

Para visualizar, abra `index.html` em um navegador moderno ou sirva a pasta por um servidor HTTP local.
